EMD Factory Panel & Admin Panel
================================

Thank you for installing EMD Group's Purchase Approval System.

INSTALLATION
------------
This installer has placed the application files in the installation directory.
You can launch the application from:
- Desktop shortcut (if selected during installation)
- Start Menu -> EMD Group -> [Application Name]
- Installation directory

SYSTEM REQUIREMENTS
-------------------
- Windows 10 or later (64-bit)
- 4GB RAM minimum (8GB recommended)
- 100MB free disk space
- Internet connection for server synchronization

GETTING STARTED
---------------
1. Launch the application
2. Enter your username and password
3. Click "Login" to connect to the server
4. The application will automatically sync with the server

FACTORY PANEL
-------------
The Factory Panel is designed for factory/site users to:
- Submit purchase requests
- Track request status
- Upload completion documents
- View request history

ADMIN PANEL
-----------
The Admin Panel is designed for administrators to:
- Review and approve/reject purchase requests
- View and manage bill uploads
- Configure factory locations
- Generate reports
